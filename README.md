# Commons Companion Vessel 1 — Miguel

A simulation-only companion-vessel reference implementation for bounded
identity continuity, user-controlled memory, consent-gated actions, and
auditable safe shutdown.

## Current evidence level

**Prototype / simulation.** This repository does not establish consciousness,
personhood, hardware readiness, or authority to perform real-world actions.

## Run

```bash
python -m miguel.demo
python -m pytest -q
```

Miguel begins in a stopped state. External action is unavailable. Trust and
familiarity may affect conversational context but never authorization.
