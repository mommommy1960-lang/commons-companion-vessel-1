# Security Policy

Do not publicly disclose live credentials, exploitable vulnerabilities, private data, or instructions enabling immediate harm. Use GitHub private vulnerability reporting when available or a previously verified private channel.

Only the current default branch is maintained until formal releases are declared. Preserve evidence, revoke exposed capabilities promptly, prefer reversible containment, and protect good-faith reporters.

Never commit passwords, tokens, private keys, seed phrases, environment files, production credentials, or unredacted sensitive datasets. Rotate any secret that reaches repository history.
