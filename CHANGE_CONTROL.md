# Change Control

- **Class 0:** documentation only.
- **Class 1:** ordinary bounded implementation.
- **Class 2:** authorization, privacy, identity, memory, external actions, safety, cryptography, or auditability.
- **Class 3:** expanded autonomy, actuation, credential scope, self-modification, physical impact, or irreversible effects.

Class 2 requires safety-impact review and rollback. Class 3 requires two-person approval, adversarial testing, a documented safety case, and an independent stop path. Emergency changes remain logged, time-bounded, and reviewed afterward.
